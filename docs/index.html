WHAT CHANGED

改善重點

沿用原本的 LINE Bot，優先完成能直接使用、也容易驗證的核心功能。

✳

文字快捷指令

翻譯、潤飾、解釋與小測驗，各有明確入口。

⌕

搜尋查證

一般問答與學習指令可使用 Google Search grounding，並附上可用來源。

☷

指令清單

輸入 /help，或直接詢問「有哪些指令」，即可查看使用方式。

⌁

保留一般聊天

直接傳送其他文字，仍可和 AI 助理一般對話。

QUICK COMMANDS

快速指令

把想做的事放在文字前面，讓 Bot 知道你要它怎麼幫忙。

翻 <文字>

翻譯成繁體中文。例如：翻 Good morning

翻英文 <文字>

指定翻譯成英文。也可用「翻日文」或「翻韓文」指定語言。

改 <文字>

修正文法，讓表達更自然。適合潤飾訊息或短文。

解 <主題>

用白話解釋主題並舉例。例如：解 什麼是遞迴？

考 <主題>

出一題小測驗，先不公布答案。回答後再繼續互動。

/help

顯示完整指令清單。問「有哪些指令？」也可以。

BUILD NOTES

開發紀錄

從程式提交紀錄整理，保留可追溯的改善脈絡。

功能改善

加入 LINE 快速指令

新增翻譯、文字潤飾、主題解釋與小測驗；並支援指定翻譯語言。

回答品質

為可查證的問答加入搜尋 grounding

一般聊天、「解」與「考」可使用 Google Search 查找資料，並在 API 提供來源時附上連結。搜尋可降低錯誤，不保證完全正確。

使用體驗

讓使用者找得到指令

支援 /help、自然語句詢問指令，並補上指令說明與安全的診斷紀錄。

原先版本

  • 以一般 AI 聊天為主
  • 較難快速指定翻譯、解釋或測驗任務
  • 容易不知道 Bot 支援哪些指令

改善版本

  • 提供六種清楚可用的快速入口
  • 可搜尋查證一般問答並附來源
  • 透過 /help 或自然語句查看功能
